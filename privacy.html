Privacy Policy

Last updated: 6 November 2026

Toolspark Uploader is a personal tool. It signs in only to the YouTube channels owned by its developer, using Google OAuth.

What it accesses

It uses the YouTube Data API only to upload videos, set thumbnails and schedule publishing on the developer's own channels, and to read the id of the signed-in channel.

What it stores

An OAuth refresh token is stored only on the developer's own computer. No data is collected from other people, and nothing is sent to any server other than Google's.

Sharing

We do not sell, share or transfer any user data to third parties. The app's use of Google user data follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
